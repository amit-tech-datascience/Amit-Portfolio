The problem

An interactive character application needs to connect browsing, saved characters and generated conversation across frontend and backend boundaries.

Conceptual illustration, not an experimental output.

My contribution

I built a Rick and Morty character application with a Next.js/TypeScript frontend and an Express backend, integrating the public character API and OpenRouter-hosted language models.

The approach

The repository includes MongoDB/Mongoose models, JWT authentication, character search, customization and chat. The chat route validates inputs, constructs persona prompts and handles upstream errors.

Results & learning

The source demonstrates full-stack AI integration, including character backstories and conversational features. Local setup instructions are available in the repository.
